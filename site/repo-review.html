What was checked file by file

  • js/*.js, docs/js/*.js — traced where numbers come from: all from hand-written objects plus local simulation; no fetch of the Kalshi API.
  • site/assets/app.js, site/*.html — reads only data/*.json; each row links to its endpoint.
  • scripts/kalshi_collector.py — public read-only endpoints only; no signing, no orders; now demo-first.
  • scripts/check_site.py — link and source-link gate used by CI; extended expectations kept intact.
  • tools/*.js — static generators for the dash/ build; no longer on the published path.
  • data/snapshot.json — spot-checked: KXAAAGASW-26NOV23-3.8400 exists on the demo host with the same rules text and open interest as the snapshot.
  • .github/workflows/pages.yml — the only workflow on main; now assembles and deploys one site.
