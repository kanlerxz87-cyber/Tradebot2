Kalshi live dashboard

Live tracking of Kalshi event contracts in five topics: gas prices, elections, culture, crypto and golf. Alerts fire when a YES price moves $0.10 or more between two collection runs. Every number links to the Kalshi API endpoint it came from.

Executive summary

The site is a read-only monitor of Kalshi’s public market data. It does not hold a trading account and cannot place real orders. The live data pipeline runs on a 15-minute schedule (GitHub Actions) and publishes static JSON to this site.

Key limits: (1) price moves are measured between scheduled runs, so “sudden” means between two snapshots, not per second; (2) the API does not say what caused a move, so cause links are reference sources only and are marked unverified; (3) the high-ROI filter is a fixed rule set, not a validated model; (4) the demo-account portfolio is not connected because it needs API-key credentials that were not provided in the chat.
