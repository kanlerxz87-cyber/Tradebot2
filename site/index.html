How to read this desk

Last is the last traded YES price; “no trade” means no contract traded in the last 24h (the API returns 0, which is not a price). Contracts at ask is the size resting at the best YES ask. 24h $ (computed) is volume × last price. Cause of a move is never claimed: the API does not report causes, so reference links are settlement/rules sources, not proof.

Refresh the page — it re-reads data/ every 30 seconds. A scheduled GitHub Actions job rebuilds that data (default: every 10 minutes).

Kalshi demo environment. Every market on this site is read live from the Kalshi demo REST API (external-api.demo.kalshi.co/trade-api/v2). Kalshi documents that demo funds are mock funds, that demo credentials are separate from production, and that demo prices and behaviour "may not be reflective of those in real markets".
