Irregularities and unverified items found while building this dashboard. These do not block the release and are published here for your review after the site is live.

Sandbox connectivity limitation. Direct outbound access to kalshi.co / kalshi.com hosts is blocked from this build sandbox (all returned SSL_ERROR_SYSCOLL / TLS errors), so the live Kalshi demo API could not be called directly during development. All API facts were taken from official Kalshi documentation surfaced via web search (docs.kalshi.com). The live site still attempts to call the demo API from the visitor's browser and reports connection status.
