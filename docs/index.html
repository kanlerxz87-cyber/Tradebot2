How it works

Five steps from signal to portfolio

1 · Discover

Live events are ranked by dollar volume across the five tracked topics.

2 · Alert

Sudden swings ≥ $0.10 fire into a scrolling chat — all events and a high-ROI filter.

3 · Signal

A heuristic model scores each swing for high-ROI potential. Not a financial recommendation.

4 · Trade

Three simulated strategies auto-execute. All trades are simulated; nothing executes real orders.

ℹ
Live or simulated?

The dashboard tries the official Kalshi demo API first. If it is unreachable — for example, from a restricted network — it falls back to clearly-labeled simulated data so every feature stays explorable.
