A clearer view of the demo market.

Gas prices. Elections. Culture. Crypto. Golf. Five separate topics, contracts grouped into events, two scrolling feeds for observed ≥$0.10 moves, interactive price windows, order-book quantities, resolution tracking and an automated paper-strategy ledger.

Current values require a successful official API read. When that fails, the desk labels the dated capture; missing values stay blank and flagged. A source link is evidence to inspect, not a promise of current connectivity.

Know what is measured. Rankings cover selected contracts, not the entire exchange. Face notional (contracts × reported face value) is not cash turnover. Polling can miss between-read swings. The selective “high-ROI” feed is a model hypothesis, not a validated return forecast. Authenticated account values and causal news attribution remain unverified.
