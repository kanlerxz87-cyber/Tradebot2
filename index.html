What is actually live

No black boxes: each layer is either measured or clearly marked as an assumption.
LIVE

Prices, alerts, orderbook

The dashboard polls the public demo API every 5 seconds for all tracked tickers, detects ≥ $0.10 moves in the browser, and refreshes the selected market’s orderbook and candles. If the API is unreachable it says so and shows the verified snapshot.

MODEL

A transparent high-ROI filter

Entry, model probability, edge, estimated ROI, spread, depth, volume and time-to-close are all published per pick. The model is a heuristic, not a forecast; its realised paper performance is tracked on the portfolio page.

UNVERIFIED

Real demo-account trading

No demo API key was supplied to this project, so balance, positions and order placement are unverified. The signed client and the V2 order endpoint are implemented; execution is disabled by default. See Flagged for review.

Sources & method. Data comes from the official Kalshi demo Trade API and documentation. Every table row links to its API record and Kalshi market page. Values that cannot be confirmed are left blank and flagged. The snapshot was generated —. Full methodology · Open issues · Earlier session archive.
