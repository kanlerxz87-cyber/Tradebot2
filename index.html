Kalshi demo — live event dashboard

The five tracked topics — gas prices, elections, culture, crypto and golf — ranked by traded dollar volume. Two scrolling feeds flag every contract move of $0.10 or more in either direction: one with all events, one filtered to the moves the model scores as high ROI. Prices, order books and results are read from the official Kalshi demo Trade API v2 and every row links back to the response it came from.

All-event swing feed · every move ≥ $0.10

High-ROI feed · model ROI on risk ≥ 25%

Filter rule: fade the move (mean reversion, 10 contracts, taker fee), keep the alert only when ROI on risk is ≥ 25% and the entry price sits between $0.10 and $0.90. Both numbers are computed, not asserted — see strategies.

Chart

x = time (UTC), y = YES contract price $0.00–$1.00. Line = mid price, band = best bid/ask, dots = captured moves ≥ $0.10.

How to read this dashboard. “Contracts at best ask” and “Ask-side $” come from the captured order book: the last price level with resting size, in contracts and dollars. “Est. 24h $ volume” is volume_24h_fp × last price — an estimate, because Kalshi reports volume in contracts, not dollars. A dash (—) means the API did not return that field; it is never filled in.
