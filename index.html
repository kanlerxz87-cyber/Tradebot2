Tradebot2 — Kalshi Demo Dashboard

A live dashboard for tracking Kalshi event contracts on the demo Trade API, focused on five topics: gas prices, elections, culture, crypto, and golf. It alerts on contract price swings of ≥ $0.10 in either direction, tracks events until they resolve (Yes / No), and supports simulated trades and portfolio performance analysis.

Demo environment — no real money. This site connects to the Kalshi demo API (https://external-api.demo.kalshi.co/trade-api/v2). Trading and portfolio endpoints require a signed demo API key, which this site never collects or asks for. Simulated trades use paper money in your browser only.

Executive summary

  • Demo REST API: https://external-api.demo.kalshi.co/trade-api/v2
  • Demo WebSocket: wss://external-api-ws.demo.kalshi.co/trade-api/ws/v2
  • Public market data: no API key required (/markets, /events, /series, /markets/{ticker}/orderbook).
  • Contracts: binary Yes/No, $0.01–$0.99, pays $1.00 if correct, $0.00 if wrong; resolves Yes or No.
  • Regulator: CFTC-regulated exchange (KalshiEX LLC).

How the dashboard works

Live tables

Each topic page lists live markets in a simple table with source links. Values that can't be confirmed from an official source are left blank and flagged unverified.

Price-swing alerts

Two scrolling chats: all events and model-preferred high-ROI, for swings ≥ $0.10 in either direction.

Charts & liquidity

Price vs time (seconds / minutes / hours), current price, and contracts available at each price (orderbook liquidity).

Verification & flagged items

Every table row carries a link to an official source. Where a value cannot be confirmed, it is left blank and flagged unverified — nothing is inferred. Review open items on the Flagged for Review page.
