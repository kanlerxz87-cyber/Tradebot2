Kalshi demo, read carefully.

A live dashboard for the Kalshi demo exchange across five topics — gas prices, elections, culture, crypto and golf. It ranks the highest-dollar live events, fires alerts on every ≥ $0.10 price swing into two scrolling chats, charts price against order-book liquidity, follows each event to its YES/NO resolution, and tests four trading strategies with simulated money.

Every figure is fetched from the official Trade API when the page loads, and every table row links to the exact endpoint behind it. Where the API returns nothing, the page shows “—” and the reason is recorded on Flagged for review — nothing is filled in.

Honest limits

  • Moves, not causes. The API publishes prices and trades, not news, so no headline is ever blamed for a move.
  • Demo ≠ production. Kalshi states demo prices may not reflect real markets and the demo carries a subset of markets.
  • Simulated money. Local, fee-aware paper trades. Reading a Kalshi demo-account balance needs signed API keys (F-06).
