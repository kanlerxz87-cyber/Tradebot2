Kalshi demo, read carefully.

A live dashboard for the Kalshi demo exchange across five topics — gas prices, elections, culture, crypto and golf. It ranks the highest-dollar live events, fires alerts on every ≥ $0.10 price swing into two scrolling chats, charts price against order-book liquidity, follows each event to its YES/NO resolution, and tests four trading strategies with simulated money.

Every figure on the site is fetched from the official Trade API when you load the page, and every table row links to the exact endpoint behind it. Where the API returns nothing, the site shows “—” and records why on the Flagged for review page instead of filling the gap.

Why this page exists

The repository used to publish a dashboard that showed invented Kalshi markets as live — tickers that do not exist, made-up news “catalysts” and a portfolio P&L built on top of them. That is the one thing a trading tool must never do.

This site is rebuilt around a single rule: if the official API did not return it, it does not appear. The old pages are preserved, clearly marked, under /legacy/.

Honest limits, up front

Moves, not causes

Kalshi publishes prices and trades, not news. This site never claims a headline caused a move.

Demo ≠ production

Kalshi states demo prices may not reflect real markets, and the demo carries a subset of markets.

Simulated money

Trades are local, fee-aware paper trades. Reading a real demo-account balance needs signed API keys.
