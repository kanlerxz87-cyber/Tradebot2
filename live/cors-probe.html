Browser CORS probe

This page asks your browser to call the official Kalshi demo API directly and prints exactly what happened — status, latency and the Access-Control-Allow-Origin header if the browser exposes it. A server-side probe (a CI runner) can succeed while a browser is blocked, or vice-versa, so this is measured in the place the dashboard actually runs.

The previous CI measurement is committed at data/probe.json (server-side, records access-control-allow-origin for the Pages origin). Official docs note that market-data responses are cached for a short time: quick_start_market_data.
