Executive summary

Last verified against the official Kalshi documentation on 22 November 2026. Every claim below links to the page it came from. Anything that could not be confirmed is listed on the Flagged for review page and is not stated as fact anywhere on this site.

1. What this project is

A read-only, browser-native dashboard for Kalshi's demo exchange covering five topics — gas prices, elections, culture, crypto and golf. It ranks the highest-dollar live events, runs two live scrolling alert chats for moves of $0.10 or more, charts price and order-book liquidity, tracks every event to settlement, and runs four simulated trading strategies whose results are categorised and analysed.

The site is static: HTML, CSS and JavaScript with no build step and no server. Data is fetched directly from the official Kalshi Trade API by the browser at request time.

4. What the dashboard does

  • Ranking. Events are ranked by traded notional (contracts × $1). 24-hour and total figures are both shown and labelled with the API field they come from.
  • Alerts. Two chats: all moves ≥ $0.10, and the subset passing a documented reversion screen. Each message links to its market and its raw API call.
  • Charts. Official 1/60/1440-minute candlesticks merged with observed snapshots; window selectable from 15 minutes to 7 days.
  • Liquidity. Resting contracts at every returned price level, with the ask side correctly derived from NO bids.
  • Resolutions. Markets are followed past close until the API publishes YES/NO.
  • Simulated trading. Four strategies, fee-aware, auto-runnable, analysed by strategy, topic, side and price band.

5. Honest limitations

  • No cause data. Kalshi publishes prices and trades, not news. This site never asserts why a contract moved; the “what may have moved it” idea is handled on the flagged page because it cannot be sourced.
  • Demo subset. Several real series have no demo markets. Empty topics are reported as empty, never filled with examples.
  • Polling, not a tape. The public page refreshes on a timer; true per-second streaming needs an authenticated WebSocket, which requires a key that is not in this repository.
  • No live account. The Kalshi demo-account balance needs signed API keys (F-06). The portfolio here is a local simulation.
  • No validated edge. The reversion screen and the four strategies are hypotheses; their results are published as-is.

6. What a trader should do with it

  1. Open the dashboard and check the freshness pill — green means data is under 2 minutes old.
  2. Use the topic pages to see one category at a time, events grouped inside each.
  3. Watch Alerts for ≥$0.10 moves; click any message to reach that market's chart and book.
  4. Judge a move by its spread, top-of-book size and 24h volume before acting — all three are on every row.
  5. Let auto-trade run for days, then read the per-strategy table instead of the headline P&L.
