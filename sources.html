How a row on this site is verified

  1. The collector calls a documented endpoint and stores the exact request URL with the record.
  2. tools/verify_data.py rejects any record without an official Kalshi source URL, any non-null value that contradicts the API's string format, and any resolved market without a yes/no result.
  3. The site renders the stored value verbatim; a dash means the API returned nothing for that field.
  4. Derived numbers name their formula next to the table (volume estimate, ROI, fee model).
