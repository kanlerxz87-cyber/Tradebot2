Verification pipeline rules

  1. The collector fetches documented public endpoints and stores the exact Kalshi API and market URLs on every row.
  2. tools/verify_data.py and tools/verify_site.py fail on missing source URLs, invalid quotes, unknown topics, or broken relative links.
  3. Any missing or unauthenticated value (such as live demo balance without an API key) renders as — and is recorded on Flagged for review.
  4. Computed metrics (notional estimate, estimated ROI, fees, backtest equity) state their exact formulas in Method & formulas.
