    Kalshi demo account

    The real demo portfolio requires a signed request with your own API key. No credential is stored in this repository or this page.
    UNVERIFIED

    Status

    No demo API key was provided to this project. Balance, positions and order placement are therefore unverified, and the Flagged for Review page says so.

    To enable authenticated reads locally:

    1. Create a demo API key at the official Kalshi demo site and download the private key once.
    2. Export KALSHI_API_KEY_ID and KALSHI_PRIVATE_KEY_PATH (or KALSHI_PRIVATE_KEY_PEM) in your shell. Never commit them.
    3. Run python -m app.server and open http://localhost:8000/portfolio.html.

    Not connected. Showing no balance rather than a placeholder.
    Assumptions in the simulator. Buys pay the ask, sells receive the bid, the general taker fee is applied, visible depth caps size, and no settlement fee is modelled. Settlement pays $1 per winning contract. Backtest entries occur at the close of the candle in which the move completed, with no latency or queue model. These assumptions are listed in methodology and on Flagged for review.
