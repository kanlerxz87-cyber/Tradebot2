Methodology

How this dashboard sources, verifies and labels data

This page documents every source used, what is verified against official docs, and what is an internal project rule or explicitly unverified. Anything not confirmed from an official source is left blank and flagged on the Flagged for review page.

Architecture

Live mode (demo API)

  • Public market data polling: GET /markets?status=open&limit=100
  • Selected-market detail: GET /markets/{ticker}
  • Orderbook depth: GET /markets/{ticker}/orderbook
  • Official endpoints: external-api.demo.kalshi.co (recommended) with demo-api.kalshi.co fallback

Simulated fallback

When the demo API is unreachable (sandbox or restricted network), the dashboard runs the built-in simulator: clearly-labeled synthetic markets with random-walk prices, news shocks, resolutions and trade execution. Everything labeled SIMULATED is synthetic — it is not market data.

What is NOT verified

See Flagged for review for the full list
  • Live demo API payload field names are best-effort and unverified — the dashboard degrades gracefully rather than guessing.
  • WebSocket channels are not enabled — the docs describe auth+headers that are not browser-safe to forge, and the feature is marked in the flagged list.
  • Values on topic pages are simulated, not demo market data.
  • “ROI” scoring is an internal heuristic, not a Kalshi product or a financial recommendation.
