Strategies — full specification

The four simulated strategies and the high-ROI alert filter, exactly as implemented in assets/sim.js and assets/live.js. All execution is paper-only (no API keys, no real orders — flag F2). The engine is deterministic: same snapshot ⇒ same trades, so results are reproducible.

High-ROI alert model (Chat 2 filter)

ParameterValueRationale (documented, not fitted)
Trigger|Δprice| ≥ $0.10Project requirement: alert on sudden swings ≥ $0.10 either direction.
Reversion coefficient K0.6Assumes 60% of a sudden dislocation reverts to the mid. Conservative starting hypothesis — must be estimated from /historical/markets data before use as a signal.
Fair estimatemodelFair = clamp(0.5 + (prev − 0.5)·K, 0.02, 0.98)Linear reversion toward 0.50, clamped away from the pins.
Edge gate|modelFair − after| ≥ $0.05Only a tradeable edge ≥ 5¢ after fees/spread is "high-ROI".
Liquidity gateopen_interest_fp ≥ 1Refuse to highlight dead markets; real sizing needs book depth (see F11).
Worked example (verified replay data)prev 0.34 → after 0.19 (Δ −$0.15): modelFair = 0.5+(0.34−0.5)·0.6 = 0.404; edge = 0.214 ≥ 0.05; OI 200.26 ≥ 1 ⇒ PASSThis is the line that reaches Chat 2 during the replay of the BTC 15-min collapse.

Limitations: single-asset reversion assumption; no cross-market information; K and the edge gate are not yet estimated from history. The model is a filter for attention, not a claim of edge — all such claims are flagged on the review page.
