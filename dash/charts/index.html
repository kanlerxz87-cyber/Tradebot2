Official semantics: the book returns YES bids and NO bids only; a YES bid at p equals a NO ask at 1−p with identical size (official orderbook docs). "Contracts available at a given price" = the size at that level, plus the resting ask sizes from the market record (yes_ask_size_fp / no_ask_size_fp).

How to read this trader's guide

  • Price history granularity — the demo API exposes 1-minute candlesticks as the finest official bucket (period_interval ∈ {1, 60, 1440}). Second-level resolution is therefore derived by deterministic linear interpolation inside each verified minute, and labeled as such in the axis selector. Switch to hour buckets for longer-context views (aggregation of the same verified minutes).
  • Y axis — contract price in dollars. Every contract settles at exactly $1.00 (yes) or $0.00 (no), so price = implied probability × $1.
  • Liquidity — two numbers matter: depth at price (how many contracts you can lift/hit at a level) and spread (yes_bid vs yes_ask). Thin books (e.g. 2 contracts) warn against size; the Portfolio simulator applies a liquidity gate for the same reason.
  • Alert band — the $0.10 band shows how far a swing must travel before it hits the alert chats on the Alerts page.
  • Live mode — when browser polling of the demo API succeeds, this explorer can be extended to append live 1-minute buckets as they print (see the suggestions on the home page).
