    How to grow this into a real strategy lab roadmap

    • 1. Keys — generate a Kalshi demo API key (docs: API Keys), then this same engine can place real paper orders on the demo account via the official order endpoints and reconcile fills through the fill websocket channel.
    • 2. History — ingest /historical/markets + 1-min/1-hour candlesticks for all five topics; re-run the four strategies over weeks of data before believing any win rate.
    • 3. Walk-forward — split data train/test, tune K (reversion) and the edge/OI gates, and report out-of-sample ROI only.
    • 4. Risk — add per-position sizing (Kelly fraction of model edge), daily loss limit, and the official order-group rolling-limit feature as a hard cap.
    • 5. Reporting — auto-generate this page hourly from data/snapshot.json so the category tables always reflect the latest verified data.
