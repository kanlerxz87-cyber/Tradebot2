Making the site more live & interactive — suggestions what to add next

  • WebSocket push instead of 15s polling — subscribe to the official ticker and trade channels (wss://external-api-ws.demo.kalshi.co/trade-api/ws/v2) for sub-second updates; the REST poller is the degraded fallback.
  • Price heatmap grid — 5 topics × active events, cells colored by 1-min Δ, so a trader sees the whole board move at once.
  • Drag-zoom + crosshair on charts with the seconds/minutes/hours axis already selectable; add range-brush and OHLC cursor readout.
  • News-correlation overlay — when a ≥$0.10 jump fires, auto-attach the market's official settlement-source link (already wired per market) and an optional RSS/keyword feed of likely causes, clearly labeled "possible cause, unverified".
  • Sound / TTS alerts for the high-ROI chat, with per-topic mute and a quiet-hours schedule.
  • One-click simulated order ticket — pick market + side + size, the paper engine (Portfolio page) executes against the live book and tracks it to settlement.
  • Event countdown + settlement watch — auto-replay the exact settlement (yes/no, settlement_value_dollars) the moment a tracked market finalizes.
  • Multi-account paper comparison — run 2–3 strategy parameter sets side by side (same engine, different K/edge/OI gates).
  • Keyboard shortcuts — 1–5 switch topics, A for alerts, C for charts, / to focus search.
  • Snapshot scheduler — a CI job that re-polls the demo API hourly, commits new data/snapshot.json, so the site never goes stale.
