How alerts fire the exact rules

  • Observation — each tracked market's last_price_dollars is sampled on every poll (live) or per replay tick. A swing is |price_now − price_prev|.
  • Threshold — alert when the swing is ≥ $0.10 in either direction (both ▲ and ▼). The threshold is the constant ALERT_THRESHOLD = 0.10 in assets/live.js.
  • Chat 1 (all) — receives every threshold-crossing line: time, market, Δ$, price, and the model's verdict.
  • Chat 2 (high-ROI) — additionally requires the model pass (below).
  • Settlement alerts — when a tracked market finalizes, the exact result (yes/no) and settlement_value_dollars from the API are posted, so every tracked event is followed to resolution.

High-ROI model (v1, fully documented): assume a fraction K = 0.6 of a sudden move reverts to the mid. modelFair = clamp(0.5 + (prevPrice − 0.5) × K, 0.02, 0.98); edge = |modelFair − priceAfter|. A swing is "high-ROI" when edge ≥ $0.05 and open interest ≥ 1 contract (liquidity gate). Example from the verified replay: prev $0.34 → after $0.19 (Δ $0.15): modelFair = 0.5 + (0.34−0.5)×0.6 = $0.40, edge = |0.40−0.19| = $0.21 ≥ $0.05, OI 200 ≥ 1 → passes to Chat 2.
